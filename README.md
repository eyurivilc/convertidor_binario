# Binarix

Conversor web local de texto y binario. Permite transformar datos entre texto, binario, ASCII, UTF-8 y Unicode, mostrando una traza por carácter, byte o punto de código.

## Requisitos

- Node.js y npm.

## Inicio rápido

```bash
npm install
npm run dev
```

## Comandos

| Comando | Descripción |
| --- | --- |
| `npm run dev` | Inicia el entorno local de Astro. |
| `npm test` | Ejecuta las pruebas con Vitest. |
| `npm run check` | Ejecuta la comprobación de Astro y TypeScript. |
| `npm run build` | Genera la versión estática de producción. |

## Stack

- Astro 7
- TypeScript
- Tailwind CSS
- Vitest

La conversión se ejecuta íntegramente en el navegador; no requiere cuentas, API ni servicios externos.

## Archivos locales

`.gitignore` excluye artefactos locales de agentes y tareas (`.atl/`, `odd/`), dependencias, compilados, variables de entorno y cobertura.
